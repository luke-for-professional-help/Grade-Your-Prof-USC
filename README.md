# Grade-Your-Prof-USC
A professor rating system for the students of the University of San Carlos. 





How to start:

1. clone repository from github.com
2. terminal command: cd linear_TestBuild/linear-app
3. install dependencies with terminal command: npm install //if you haven't already
4. run local dev server
   terminal command: npm run dev  
5. type 'o' in terminal to open the website in the browser. 
6. Frontend can see files in src/lib/components and src/routes
7. Backend can go and SUCK ITTTTTTT
