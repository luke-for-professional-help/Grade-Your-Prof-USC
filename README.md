# Grade-Your-Prof-USC
A professor rating system for the students of the University of San Carlos. 





How to start:

1. clone repository from github.com
2. terminal command: cd linear_TestBuild //do this first    because the terminal doesn't see the other directory
   terminal command: cd linear-app
3. terminal command: npm install
4. run local dev server
6. npm run dev -- --open
7. type 'o' in terminal to open the website in the browser. 
8. Frontend can see files in src/lib/components and src/routes
9. Backend can go and SUCK ITTTTTTT
